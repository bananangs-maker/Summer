# MOTION 학습 캘린더

2026-11-15. 운동 기능과 인지 관찰 프로토콜은 유지하고 학습의 메인을 캘린더로 변경했다.

## 사용 순서

1. 목표에서 이름·색·시작일·종료일·학습 요일을 설정한다. 시험일은 별도 선택 사항이며 한국 날짜 기준 D-day를 표시한다.
2. 세부목표에 이름·전체 정수 분량·단위·시작 번호를 입력한다. 예: 교재 100페이지 1회독, 100/페이지/1.
3. 자동 배분을 선택하면 시작 날짜부터 지정 학습일수에 나눈다. 선택 요일과 목표 기간에 해당하고 학습 휴가가 아닌 날짜를 사용한다. 직접 입력을 선택하면 세부목표를 먼저 저장하고 캘린더에서 계획을 하나씩 추가한다.
4. 자동 배분의 기본 비중은 평일1:주말2이며 1~5배 중 선택한다. 각 날짜 최소1단위를 우선 배정하고 나머지를 비중에 따라 정수 배분한다. 잔여는 소수부가 큰 날짜부터, 동률이면 날짜순 배정한다. 전체 분량과 배정 합계는 일치하며 범위는 끊기거나 겹치지 않는다.
5. 캘린더에서 날짜를 선택해 계획 완료를 체크한다. 미래 날짜와 휴가일은 완료 체크가 비활성화된다. 페이지 범위·분량·날짜를 수정할 수 있지만 같은 세부목표의 분량 중복을 허용하지 않는다. 완료 계획의 내용/날짜를 바꾸면 확인 후 완료 체크를 해제한다.
6. 이미 완료한 계획이 포함된 세부목표의 자동 재배분은 금지한다. 개별 계획 수정은 가능하다. 미완료 계획의 자동 재배분은 확인 후 해당 세부목표의 기존 계획을 대체한다.

## 달성률

목표의 선택 학습 요일에 해당하는 시작일~종료일 전체 날짜가 분모다. 미래 학습일도 포함하며 학습 휴가만 제외한다. 계획이 없는 학습일은 완료로 세지 않는다. 해당 목표의 그 날짜에 배치한 모든 세부계획이 완료되어야 하루 달성으로 센다. 세부목표나 과제 수가 많아도 하루 완료는 한 번이다.

목표 달성률 = 완료한 학습일 / (예정 학습일 − 해당 날짜의 학습 휴가) ×100.

평균 달성률은 산출 가능한 모든 목표의 달성률을 산술평균한다. 목표 기간·페이지 수·주말 배분·공부 시간에 가중치를 주지 않는다. 예:100일 중50일=50%,10일 중8일=80%이면 평균65%. 목표 종료 후에도50%는50%로 남으며 자동으로100%로 변하지 않는다. 종료 목표를 평균에 포함한다. 과거 기록을 수정하면 해당 결과는 재계산된다.

학습일 전부가 휴가인 목표는 분모가0이므로 산출 불가로 표시하고 평균에서 제외한다. 목표가 없거나 산출 가능한 목표가 없으면 평균은0%가 아닌 ‘—’로 표시한다. 날짜마다 모든 목표를 한데 묶어 완료시키지 않고, 목표별 하루 달성을 따로 판정한다.

## 학습 휴가

운동 휴가와 별도로 달력 월당2일, 이월 없음. 같은 휴가일은 모든 학습 목표에 공통 적용된다. 미래 휴가 예약도 가능하다. 달성률의 분모와 완료일 모두에서 제외하며 완료 점수를 주지 않는다. 취소하면 본래 학습일로 복귀한다.

휴가 선언은 기존 계획을 삭제·이동하거나 자동으로 분량을 다시 나누지 않는다. 계획과 완료 상태는 그대로 보존된다. 새 자동 배분에서 휴가 날짜를 건너뛰며, 이미 배정된 학습량은 개별 계획의 날짜를 수정해 이동할 수 있다. 휴가3일째는 저장 검증과 UI 양쪽에서 제한한다.

## 저장과 호환

기존 `motion-observation-v1` 브라우저 저장소의 `learning` 하위에 저장한다. 목표·세부목표·개별계획·휴가를 건강 기록 JSON 백업에 함께 포함한다. 예전 건강 백업에 learning 필드가 없어도 읽을 수 있다. 예전 학습 시간·수면·인지 원자료는 보존한다. 현재 서버는 로그인 없는 공용 운동 기록 저장소이므로 신규 학습/건강 자료를 서버로 전송하지 않는다. 기기 간 자동 동기화가 없으며 정기 JSON 백업이 필요하다.

목표 삭제·세부목표 삭제 시 연결 계획을 함께 삭제하며 확인과 사전 JSON 다운로드를 제공한다. 계획 직접 삭제도 확인한다. 다중 탭 업데이트에는 기존 건강 기록의 revision 검사를 사용한다. 손상된 저장소를 자동 초기화하지 않는다.
