# MOTION 인지 관찰 · 학습 · 수면 / 1.0

2026-11-15. 구현 상태: 개인 관찰용 자체 과제. 임상적 타당도·재검사 신뢰도 미검증.

## 목적과 중요한 구분

실제 수행 응답을 보존하고 개인의 장기 추이를 살피는 기능이다. 디아제팜의 인지 부작용 검출기, 치매 선별검사, 진단 도구, 약물 조정 도구가 아니다. 약물·수면·우울·피로·운동의 원인별 효과를 분리하거나 인과 추론하지 않는다. 현재 복약 중 시작한 기준선은 약 복용 전 기능을 나타내지 않는다.

엄격한 임상적 정확성은 이번 자체 구현으로 충족했다고 주장할 수 없다. 연구에서 쓰인 과제 형식과 비슷하다는 사실이 동일한 타당도를 부여하지 않는다. 정식 의료 평가가 필요할 경우 한국어와 해당 연령·상황에서 검증되고 적법하게 사용 가능한 검사를 전문가가 선정해야 한다.

## 구현한 흐름

1. 사전 조건: 기기 별칭, 반응 입력 방식, 복약 상태(미기록 가능), 복용량 메모·시각(선택), 졸림 0~10(자체 숫자 척도), 방해 없는 환경 확인.
2. 독자 기호–위치 과제: 기하 기호 6개를 3×3 위치에 무작위 배치해 20초 제시. 즉시 6문항 회상. 문항당 응답 제한 15초. 무응답은 -1로 보존.
3. 독자 주의 반응 과제: 3분, 자극 간 대기 1~4초, 자극 제시 후 최대 1.5초 응답. 시각 자극만 사용. 반응 입력은 키보드 스페이스 또는 포인터 중 사전 고정. 자극 제시는 requestAnimationFrame, 반응시간은 performance.now를 이용한다. 모니터의 실제 광학적 표시 시각·하드웨어 지연을 측정하거나 교정하지 못한다.
4. 독자 역순 숫자: 2~7자리 각 2회, 총12회. 숫자당 800ms와 공백200ms. 15초 내 역순 입력.
5. 최초 기호–위치 6문항의 지연 회상. 실제 지연 구간을 기록한다. 지연은 즉시 회상 종료부터 지연 회상 시작까지이며, 설명 화면을 읽는 시간도 포함한다. 따라서 일정한 지연 기억 검사로 표준화됐다고 볼 수 없다.
6. 원자료와 상태를 로컬 보존. 게임 보상과 검사 결과는 독립적이다.

## 산출식과 운영 규칙

- 반응시간 중앙값 = 100ms 이상 실제 반응들의 중앙값(ms). 무응답/예측 입력을 임의 반응시간으로 대입하지 않는다. 유효한 실제 반응이 없으면 산출 불가.
- 느린 반응 = 500ms 이상인 실제 반응 수. 무응답은 별도. 연구의 PVT-B 355ms 기준을 임의로 이 앱의 임상 경계값으로 사용하지 않는다. 500ms도 설명적인 분류일 뿐 정상·비정상 경계가 아니다.
- 예측 입력: 자극 전 또는100ms 미만 반응. 응답 누락: 자극 후1.5초 내 응답 없음.
- 기억: 즉시/지연 각각 정답 수 /6. 역순 숫자: 정답 수 /12, 성공한 최대 자릿수. 모두 해당 과제 수행 점수다. 전체 기억력·IQ·인지력 %로 환산하지 않는다.
- 첫 전체 완료는 연습. 같은 기기 별칭·반응 방식에서 다음 24시간 이상 간격 완료3회를 초기 참고값으로 선정한다. 이후7일 간격으로 필수 관찰을 표시한다. 이 주기는 제품 운영 규칙이다. 임상적으로 검증된 권고 주기가 아니다.
- 참고값은3회의 지표별 중앙값. 신뢰구간·RCI·유의한 저하·정상치·뇌 나이 등은 산출하지 않는다. 검증된 재검사 오차와 개인·연령·언어에 적합한 규준이 없기 때문이다.
- 기기 이름이 같아도 실제 기기·브라우저가 같다고 보장되지 않는다. 브라우저/화면 메타데이터를 원자료에 남긴다. 변경 시 별칭을 새로 지정한다.
- 미측정과 낮은 점수에 감점·가상 뇌 축소를 적용하지 않는다. 운동 게임의 기존 규칙과 구분한다.

## 품질 관리와 현재 한계

탭 숨김, 창 포커스 이탈, 화면 크기 변경, 직접 중단, 큰 자극 타이밍 지연은 비교 제외 사유로 기록한다. 미완료 세션은 새로고침 후 중단 기록으로 복구한다. 완료 과제 수와3분 측정 조건도 검사한다. 예외가 없는 완료 기록이라는 뜻은 임상적으로 유효하다는 뜻이 아니다.

문항을 무작위로 생성하지만 동등 난이도와 교체 문항 효과는 검증되지 않았다. 첫 연습을 제외해도 연습 효과가 제거되지 않는다. 화면·기기·운동 속도·시력·손 조작·졸림·기분 등의 영향이 남는다. 자가 응답과 자가 환경 확인을 독립적으로 검증할 수 없다. 코드 테스트는 계산과 저장의 동작 검증이며 의학적 타당도 검증이 아니다.

## 학습·수면·시각화

- 학습은 날짜·시간(분)·선택적 내용만 입력. 학습과 복습을 구분하지 않는다. 시간만으로 기억 반감기·기억 확률·학습력 상승률을 추정하지 않는다.
- 취침/기상은 한국 시간으로 입력. 침대에 머문 시간은 두 시각의 차이. 실제 수면·수면 효율·수면 단계는 알 수 없다. 낮잠은 구분하고 중복 시간은 거부한다.
- 기상 목표 차이는 하루의 원형 시간 차이(−720~720분). 낮잠은 기상 추이에서 제외한다. 과수면을 인지 손상으로 환산하지 않는다.
- 최근7일 공부일·운동일·수면 기록일은 같은 크기의 활동 점으로 나타낸다. 이는 기록 시각화이며 신경망의 생물학적 시뮬레이션이 아니다. 기록이7일 범위에서 벗어나 점이 줄어도 인지력이 줄었다는 뜻이 아니다.
- 운동은 기존 서버 기록을 읽어 시각화에 연결한다. 운동시간 또는 칼로리에 고정 인지력 배수를 부여하지 않는다.

## 개인정보·데이터 경계

기존 서버는 인증 없는 공용 단일 기록 저장소다. 새로운 건강 기록은 `motion-observation-v1` 브라우저 저장소에만 보존하며 운동 API 상태에 포함하지 않는다. 같은 출처의 다른 탭과 같은 브라우저 사용자는 접근할 수 있고 별도 암호화되지 않는다. 다중 기기 동기화는 지원하지 않는다. 배포 URL과 파일로 연 미리보기의 저장소도 다르다.

운동 백업과 건강 백업은 별개다. JSON은 문항별 응답·원자료·검사 조건을 포함한다. CSV는 세션 요약과 복약 맥락을 포함하므로 개인이 보관·전달 대상을 결정한다. 브라우저 데이터 삭제 전 JSON을 백업해야 한다. 복원은 형식·수치·중복·시간 겹침을 검증한 후 기존 건강 기록을 교체하며, 교체 전 원본을 다운로드한다. 손상된 저장소를 자동으로 초기화하지 않는다.

## 연구 근거와 사용 권한 확인

1. Basner M, Mollicone D, Dinges DF. 2011. Validity and Sensitivity of a Brief Psychomotor Vigilance Test (PVT-B) to Total and Partial Sleep Deprivation. Acta Astronautica69:949–959. https://pmc.ncbi.nlm.nih.gov/articles/PMC3197786/ . 주의 반응 과제의 연구 배경이며 이 구현의 검증 자료가 아니다.
2. The 3-Minute Psychomotor Vigilance Test Demonstrates Inadequate Convergent Validity Relative to the 10-Minute Psychomotor Vigilance Test Across Sleep Loss and Recovery. 2022. https://pmc.ncbi.nlm.nih.gov/articles/PMC8885985/ . 짧은 과제를 긴 표준 과제와 동등하다고 가정하지 않은 근거.
3. Basner et al. 2020. Cognition Test Battery: Adjusting for Practice and Stimulus Set Effects for Varying Administration Intervals in High Performing Individuals. https://pmc.ncbi.nlm.nih.gov/articles/PMC7375457/ . 반복·문항 효과를 자동 제거했다고 주장하지 않은 근거.
4. Karr et al. 2024. Test–Retest Reliability and Reliable Change on the NIH Toolbox Cognition Battery. https://pmc.ncbi.nlm.nih.gov/articles/PMC11345114/ . RCI가 해당 검사의 신뢰도와 재검사 조건에 의존함을 확인. 이 앱에 논문의 경계값을 복사하지 않음.
5. NIH Toolbox. Cognition Tests: Access and Materials. https://nihtoolbox.zendesk.com/hc/en-us/articles/10395002828436-Cognition-Tests-Access-and-Materials . 자격·사용 조건 확인. 해당 검사·문항·점수 체계를 복제하지 않았고 NIH Toolbox 구현을 표방하지 않음.
6. TestMyBrain. https://www.testmybrain.org/dashboard/tmb-tests.html 및 https://cogsci.testmybrain.org/ . 한국어를 포함한 검증 도구 후보이나 사용·등록 조건이 있어 임의 내장하지 않음. 향후 적법한 사용 가능 여부를 확인할 후보.
7. DailyMed Valium label. https://dailymed.nlm.nih.gov/dailymed/drugInfo.cfm?setid=260e2041-2bb3-482f-850e-b5d47a7bdbe6 . 각성 저하·전향성 기억상실 등 공식 정보. 부작용 존재는 사용자의 발생 여부나 원인을 입증하지 않음.
8. Settles & Meeder. 2016. A Trainable Spaced Repetition Model for Language Learning. https://aclanthology.org/P16-1174/ . 문항 회상 이력 없는 공부 시간만으로 개인 기억 확률을 계산하지 않은 근거. 앱 내 회상 과제와 사용자가 공부한 내용의 기억을 혼동하지 않음.

향후 정확도 향상 순서: 적법한 한국어 도구 선정 → 해당 기기·환경에서 시간 측정 확인 → 동등 난이도 문항 검증 → 반복 측정 신뢰도·연습 효과 확인 → 적합한 기준에 따른 변화 해석. 현재는 이 과정을 완료하지 않았으므로 결과를 기술적 관찰값으로 제한한다.
