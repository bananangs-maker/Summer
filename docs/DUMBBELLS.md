# MOTION 덤벨 6종 · 2026-11-16

## 일정과 기본 루틴

월·수·금·일: 풀업+푸쉬업. 화·목·토: 러닝/배드민턴 중 하나 이상 + 아래 덤벨6종 모두.

| 순서 | 종목 | 기본 세트 | 목표 횟수 | 휴식 초 |
|---|---|---:|---:|---:|
|1|덤벨 로우|2|8~12|105|
|2|덤벨 숄더 프레스|2|8~12|105|
|3|해머 컬|2|10~15|75|
|4|덤벨 컬|1|10~15|75|
|5|벤트오버 리버스 플라이|2|12~20|75|
|6|사이드 레터럴 레이즈|2|12~20|75|

이는 대화에서 제안한 루틴을 앱의 기본 목표로 옮긴 것이며, 특정 기관의 동일한6종목 처방을 복제한 것이 아니다. 설정에서 세트·최소/최대 횟수·휴식·증량 단위를 수정할 수 있다. 모든 종목을1세트로 입력하는 시작용 버튼도 있다. 자동 증량하지 않는다.

## 기록 방식

운동 후 `운동 → 운동 기록 → 덤벨6종 한꺼번에`에서 수행한 종목의 실제 횟수를 입력한다. 빈 종목은 기록하지 않는다. 기록이 있는 모든 종목을 한 번의 상태 저장으로 원자적으로 저장하며 한 항목이라도 잘못되면 전체 저장을 거부한다. 종목별 기록·수정·삭제도 지원한다.

- 중량은 덤벨 한 개의 kg. 외부 중량이 실제 칼로리에 선형 비례한다고 가정하지 않는다.
- 양팔 동시: 양팔을 함께 움직인 동작1회를1회로 입력.
- 한 팔씩: 좌우 각각 수행한 횟수를 한쪽 기준으로 입력. 기본 로우가 이 방식이며 다른 종목도 선택 가능.
- 좌우 횟수가 다를 때는 같은 횟수를 수행한 기준으로 기록하고 차이는 메모한다. 좌우 독립 원자료 모드는 이번 버전에 없다.
- 한 운동에서 중량이 달랐다면 중량별로 기록을 나누어 추가한다.
- 세트별 실제 횟수는 `12 / 10`처럼 입력한다. 클리어는 별도 수동 선택이며 의무 출석·증량과 독립이다.
- 실제 반복 횟수가 양수인 기록이 있으면 종목 출석이다. 세트·횟수 목표에 미달해도 출석은 인정한다.
- 일괄 기록의 전체 소요 시간은 선택이다. 입력 시 추정 동작 시간 비율로 종목별 총 시간을 나눠 보존한다. 소수 분배가 생길 수 있어 개별 편집은 소수 입력을 허용한다. 휴식시간 자체에 저항운동 MET를 부여하지 않는다.

## 진행과 그래프

서로 다른 두 운동일에 같은 중량·횟수 방식으로 목표 세트 모두 상한 횟수 이상이면 설정한 최소 증량 단위만큼 ‘증량 검토’를 표시한다. 최신 기록의 중량이 달라지면 새 중량에서 다시 횟수를 쌓는다. 같은 날 추가 기록만으로 두 번 달성했다고 보지 않는다. 이는 앱의 운영 규칙이며 자동 처방이 아니다.

각 종목의 일별 최고 한 개 중량, 기록 횟수 합계, 최고 세트 횟수, 양쪽 합산 볼륨을 그래프로 볼 수 있다. 볼륨=한 개 중량×기록 횟수×2. 이 값은 근육 증가량·1RM·기계적 일의 측정값이 아니다. ‘한쪽 기준’과 ‘양팔 동시’ 방식이 바뀌면 횟수 추이를 해석할 때 고려해야 한다.

## 의무·날씨·휴가·과거 호환

`dumbbellStart`는 최초 적용 날짜를 서버와 HTML 미리보기에 각각 한 번 저장한다. 그 이전 날짜의 의무는 기존 규칙을 따른다. 옛 백업은 읽을 수 있고 처음 불러온 날짜부터 새 의무를 적용한다. 실제 사용 시작일 이전으로 새 의무를 소급하지 않는다.

덤벨 적용 이후 화·목·토의7개 의무는 유산소1슬롯+덤벨6슬롯이다. 모두 수행하면+100XP, 유산소 두 종목이면+125XP. 미충족이면 누락 슬롯/7×80을 반올림해 감점한다. 덤벨 한 종목만 누락하면 약−11XP다. 가상 체중 되돌림도 누락 슬롯/7 비율을 적용한다. 마감은 기존대로 다음 날04:00다.

비·눈은 유산소 슬롯만 면제한다. 실내 덤벨6종은 유지한다. 날씨 미확인 시 유산소 슬롯만 보류하고 확인 가능한 덤벨 누락은 계산한다. 운동 휴가는 전체 의무와 되돌림을 면제한다. 학습 휴가와 운동 휴가는 별개다. 운동하지 않은 날의 가상 체중 되돌림은 실제 지방 증가 예측이 아닌 기존 게임 규칙이다.

## 에너지 근거와 한계

2024 Adult Compendium의 일반 저항운동 대용값으로 보통3.5MET(02054), 높음6.0MET(02050)를 사용한다. 개별 해머컬·레터럴레이즈 등6종의 정확한 에너지 소모를 입증한 값이 아니다. 실제 동작 시간이 없으면 기록 횟수×3초로 추정하며 한 팔씩은 양쪽 시간을 합쳐2배로 계산한다. 명시된 총 소요 시간이 더 짧으면 동작 시간을 그 값으로 제한한다. (MET−1.3)×가상 체중×3.5/200×동작 분으로 순소모를 추정한다. 표준 MET를 실제 동작 시간에만 적용하는 단순하고 보수적인 모델이며 정확도를 보장하지 않는다. 중량을 무겁게 입력했다고 칼로리를 비례 증폭하지 않는다.

출처: Compendium of Physical Activities, Conditioning Exercise, 2024, codes02050/02054, https://pacompendium.com/conditioning-exercise/ . 같은 페이지의 맨몸운동3.8/7.5MET는 기존 풀업·푸쉬업에 유지한다.

## 저장·배포·검증

덤벨은 기존 운동 상태의 logs와 dumbbellConfig에 저장하고 운동 JSON/CSV 백업에 포함한다. 기존 인증 없는 서버 구조를 바꾸지 않았다. 학습·수면·복약·인지 기록의 브라우저 저장 영역과 분리되어 있다. 새로 유료 서비스를 추가하지 않는다.

`python3 -m unittest discover -s tests -q`: 필수6종+유산소, 누락비례, 비/눈·미확인 날씨의 부분면제, 운동휴가, 적용일 이전 의무 보존, 중량/횟수 기준 검증, 그룹 저장 원자성, 서버/HTML 모델의 결과 일치 등을 검사한다. `node tests/test_dumbbell_core.cjs`는 증량 표시·동일 날짜 중복 방지·중량/볼륨 그래프 집계를 검사한다.

## 내 기준 중량 확정 · 자동 입력

종목별로 직접 체감해 선택한 중량을 별도의 `dumbbellLoads`에 확정해 보관한다. 임상적 적정성이나 풀업/푸쉬업에서 환산한 추천값을 의미하지 않는다.

- 일괄 기록에서 종목별 중량을 입력하고 `현재 중량을 내 기준으로 저장`을 누르면 입력된 중량들을 한 번에 확정한다. 실제 세트·횟수 입력 없이 기준만 저장할 수 있으며 운동 출석이나 칼로리를 만들지 않는다.
- 개별 기록에서도 `기준 중량으로 확정` 버튼으로 해당 종목 하나만 변경할 수 있다.
- 신규 기록은 확정 기준을 최우선으로 사용한다. 기준이 없으면 최근 실제 기록의 중량을 임시로 불러오고 ‘기준 미확정’으로 표시한다.
- 일회성으로 다른 중량을 입력해 실제 운동을 저장해도 기준 중량은 바뀌지 않는다. 일괄 기록 저장 후 다음 입력에는 원래 기준 중량을 다시 채운다. 기준을 바꾸려면 확정 버튼을 명시적으로 누른다.
- 작성 중인 횟수나 직접 바꾼 중량은 주기적인 상태 갱신으로 덮어쓰지 않는다.
- 과거 기록 수정 시에는 현재 기준이 아닌 해당 기록 당시 중량을 우선 표시한다. 기준 변경만으로 과거 기록을 재작성하지 않는다.
- 운동 설정·백업의 종목별 ‘내 기준 중량’에서도 변경하거나 공란으로 해제할 수 있다. 기준을 해제하면 최근 기록 임시값을 사용한다.
- 기준값은 운동 JSON 백업 및 기존 서버 상태에 포함한다. 과거 백업에 이 필드가 없어도 읽을 수 있다. 증량 검토 표시는 별도의 실제 수행 기록을 기반으로 하며 중량을 자동 변경하지 않는다.

검증: `node tests/test_dumbbell_baseline.cjs`에서 기준 우선순위·최근 기록 대체·미입력 상태·잘못된 값 거부·작성 중 입력 보존을 확인한다. Python 검사에서 기준 확정만으로 운동 기록·점수·가상 체중이 바뀌지 않음을 확인한다.
